## 🚫 Generative AI Policy (No AI Policy)

This project maintains a **strict zero-tolerance policy regarding the use of generative AI tools** (such as GitHub Copilot, ChatGPT, Claude, Gemini, and similar AI code generators) for writing code, tests, documentation, or pull request descriptions.

### ⚖️ Guidelines:
1. **Human-Authored Content:** Every line of code submitted must be written by you. You must fully understand your implementation and be ready to explain and defend your architectural choices during code review.
2. **What is Prohibited:** 
   - Generating complete functions, classes, unit tests, or entire files.
   - Using AI tools to automatically apply fixes or address code review feedback.
3. **What is Permitted:** You may use AI strictly as an advanced search engine—for initial research, learning third-party API documentation, diagnosing errors locally, or studying theoretical algorithms (provided that no AI-generated code is directly copied into the repository).

### 🛠️ Why This Policy Matters:
- **Code Quality & Maintenance:** AI-generated code often introduces subtle bugs, logical gaps, and architectural debt. We value our maintainers' and reviewers' time and will not spend it debugging LLM "hallucinations."
- **Legal & Licensing Integrity:** We must guarantee the legal provenance and copyright cleanliness of our codebase. AI models are trained on varied datasets and can inadvertently reproduce code that violates third-party software licenses.

*Any Pull Request found to violate this policy, or strongly suspected of containing unverified AI-generated content, will be closed immediately without review.*
